# Small Business Profitability Analysis

## 1. Project Overview
This project analyzes retail business data to understand
sales performance, profitability, product performance,
and regional business trends using Python.

## 2. Problem Statement
Small businesses need to understand which products,
categories, and regions generate profit and which
areas contribute to financial losses.

## 3. Objectives
- Analyze total sales and profit.
- Calculate profit margins.
- Identify profitable product categories.
- Find loss-making products.
- Analyze monthly profit trends.
- Study the impact of discounts.

## 4. Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Kaggle Dataset

## 5. Dataset
Source: Kaggle Sample Superstore Dataset

Records: 9,994
Columns: 21

## 6. Key Findings
- Total Revenue: $2,297,200.86
- Total Profit: $286,397.02
- Total Orders: 5,009
- Profit Margin: 12.47%

Technology is the highest-profit category.

Furniture is the lowest-profit category.

Tables, Bookcases and Supplies show
negative overall profit.
